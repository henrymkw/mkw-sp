From here, we can pretty easily do the following:

1. Sender sends a request to join a friend with their friend's profileId
2. To get the friend list of the sender, we first get the senders Player by using the senders SearchId. Since player has a LoginInfo, which (now) has a friend list, we have access to the sender's friend list.
  - Looking up the profileId to get the the LoginInfo seems insecure since profileIds are both public and permanent. I get spoofing concerns.
3. Get the friend list of the sender's friend (their profileId). We can do this easily by getting logins[profileId]. We need to do a number of checks, like checking if the login exists, if the login's player exists
4. We have both friend lists at this point, so we need to check if they're friends
  - if the host has open host, let them join
  - else, if both lists contain each other, let them join
  - else, don't let them join
